## Project Requirements for QA Automation Project

### Functional Areas to Test

#### 1. **Login Page**
- Validate successful login with correct credentials.
- Verify error messages for incorrect credentials.
- Ensure that both username and password fields are mandatory.

#### 2. **File Upload**
- Validate that users can successfully upload supported file types.
- Verify confirmation messages upon successful file upload.
- Test the behavior with unsupported file types.

#### 3. **Drag and Drop**
- Check that elements can be dragged and dropped.
- Ensure the order of elements updates correctly after dragging.
- Validate no visual or functional errors occur during the drag-and-drop operation.

#### 4. **Broken Images**
- Identify and report any images that fail to load.
- Verify if alternative text is displayed for broken images.

#### 5. **Dynamic Content**
- Validate that content dynamically updates when reloading the page.
- Ensure the dynamically loaded elements are consistent with expected functionality.

#### 6. **Status Codes**
- Test HTTP status codes (200, 404, 500, etc.).
- Ensure the application displays the correct response for each status code.

---

### Objectives
1. Execute manual testing for the defined functionalities.
2. Document any defects found during testing.
3. Automate selected test cases using Selenium.
4. Provide detailed reports that mimic real-world QA workflows.
5. Practice version control and collaboration using Git.
